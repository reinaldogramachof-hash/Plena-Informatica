# Supabase

Esta pasta recebera artefatos versionados quando a integracao for ativada.

## Estrutura

- `migrations/`: migracoes SQL criadas pelo Supabase CLI.
- `functions/`: Edge Functions e dependencias compartilhadas.
- `tests/`: testes de RLS e contratos de banco.

Nenhuma migracao foi criada nesta fundacao porque a primeira fase do Hub e
inteiramente local.

Antes de conectar o projeto, consulte `../docs/SUPABASE.md`.
