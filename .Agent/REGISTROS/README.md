# Registros dos agentes

Os registros são históricos e append-only.

## Regras

- Usar datas no formato `AAAA-MM-DD`.
- Informar horário com `America/Sao_Paulo` quando relevante.
- Não apagar registros anteriores.
- Correções devem ser feitas por um novo registro que referencie o anterior.
- Não incluir credenciais, tokens, dados pessoais ou conteúdo de clientes.
- Usar linguagem factual e evidências verificáveis.

## Destinos

- `DECISOES.md`: decisões permanentes de arquitetura, produto ou processo.
- `FEEDBACKS.md`: feedbacks que alteram a forma de colaboração.
- Registros detalhados de ação podem ser criados nesta pasta com o nome:
  `AAAA-MM-DD-HHMM-agente-assunto.md`.

## Exemplo de nome

`2026-06-11-1430-codex-roadmap-ferramentas.md`
